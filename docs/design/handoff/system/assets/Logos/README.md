# Logos

The mark: a K of four bars, cut flat at its frame's top, bottom and right edge. It is the only logo; there is no wordmark. Where a name is needed beside it, set "Knot" in SF Pro Semibold.

- `knot-mark.svg`: the mark as supplied, single ink `#000000`, on a 256 × 256 frame with the bars touching the frame's top, bottom and right edges. Use on light grounds.
- `knot-mark-white.svg`: the same paths, single ink `#FFFFFF`, for dark grounds and imagery.

Rules:

- Recolour with any single ink (in the apps, a template image takes the context's colour); never change the shape, the cuts, the proportions or the gaps between the bars.
- Give it clear space of at least a third of its width on every side, except where a frame (an icon, a complication) supplies it.
- Use it only where Knot stands for itself outside its windows: the app icon, widgets, Lock Screen accessories, complications, the Mac menu bar extra (template image, 16 pt tall) and the Live Activity. Never inside a note, a toolbar or a row.
- No outlines, gradients, shadows, glass effects drawn on, or red.
