# Settings

The short list of things a person may want to change, as a grouped `Form`.

**Provide:** the current values; when they can't be read, the footer "Settings can't be read right now." with every row disabled.

- Rows: Add to a note for (append window, a `Stepper`, minutes), Tidy up transcripts (`Toggle`), English (a `Picker` in menu style: Follow the region, US, UK, Australia…), iCloud sync (`Toggle`), Export all notes…, Recently deleted, About Knot. On the Mac add Hotkey and Open at login.
- Explain a setting in its section footer, in one sentence, only when its name is not enough.
- Toggles keep the system green. Don't add sections for things nobody asked for.
