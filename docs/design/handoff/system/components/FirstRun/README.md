# FirstRun

The stream the first time it is seen: one line of fact, one of sync, and up to three setup rows.

**Provide:** whether sync is on, and which setup rows still apply.

- "No notes yet." in `ios-body`, then "iCloud sync is on." in `ios-footnote` `label-secondary` with `icloud`.
- Setup rows: Record with the Action Button, Add a Lock Screen control, Add the Watch complication. Each has a glyph, a sentence and an `xmark` to dismiss; tapping explains the system steps in a sheet.
- A row disappears for good when done or dismissed; when all three are gone, the section is gone.
- Don't add illustrations, a walkthrough, or a "Get started" button.
