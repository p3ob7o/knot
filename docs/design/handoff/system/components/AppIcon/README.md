# AppIcon

The mark on the four system icon appearances: default, dark, clear and tinted.

**Provide:** the mark's four bars as four layers in Icon Composer over a plain ground.

- Default: ink bars on paper. Dark: paper bars on ink. Clear and tinted: the system renders the layers as glass in the person's choice.
- Keep the mark's shape, cut edges and proportions; centre it optically with generous margin.
- Don't add gradients, red, shadows, a border or a second shape.
