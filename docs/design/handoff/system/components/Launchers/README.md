# Launchers

Widgets, controls and the Live Activity: ways in that show state, never note text.

**Provide:** how many captures wait, how many need you, and while recording, the elapsed time.

- Small widget: the mark (`widgetAccentable`), "Knot", and one state line or nothing. Lock Screen: the mark. Both open the capture surface on the keyboard.
- Control: "Record" with `mic`; while live, `stop.fill` in `record` with the timer. Recording runs through an `AudioRecordingIntent`.
- Live Activity: a red dot, "Recording", the timer, a stop button. Dynamic Island compact: `mic.fill` in `record` and the timer; minimal: `mic.fill`.
- Don't make medium or large widgets, and never show note text outside the app.
