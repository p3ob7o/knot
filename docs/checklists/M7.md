# M7 · TestFlight v1

You can install Knot from TestFlight on every device.

One short sitting. [How to use a checklist](README.md#how-to-use-a-checklist).

## Sitting 1 · Export, install, smoke

Start when the TestFlight build is available to you. It installs over the M6 milestone build, which has the same identifier and development signing. The Mac rows use your other Mac, never the build Mac.
