# M4 · Mac and sync

You can tap the hotkey to type and hold it to record, over a full-screen app. You can use `knot` and the MCP server from Claude Code. You see notes sync both ways between the iPhone and the Mac.

About 45 minutes, in three sittings: CLI and MCP, the hotkey, and two-device sync. [How to use a checklist](README.md#how-to-use-a-checklist).

Every row names its Mac. The **build Mac** holds no real notes, so from M4 on it runs development builds only, in the development container, with `knot-dev`. Sitting 1 removes the earlier milestone build from it. Your **other Mac** is where your real notes live from the M4 milestone build on, and it gets its first Knot install in sitting 3.

The two-device rows pass on development builds first. Only then does the M4 milestone build open sync on your notes, after an export of the iPhone's store (rows M4.3-08 to M4.3-19).

## Sitting 1 · CLI and MCP

Start when `scripts/install.sh` has reported success for development builds on the iPhone and the build Mac. Before the first row:

- Sign both devices into the same iCloud account, with sync on.
- Turn command-line access on in Knot's Settings on the build Mac.
- Pick one personal folder on the build Mac for the agent, outside every worktree and outside iCloud Drive. Its path is not written here; "the agent folder" below means that folder.
