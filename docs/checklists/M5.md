# M5 · iPad Pencil

You can write by hand, search the handwriting, copy it as text, and see the drawing on the Mac and the iPhone.

About 20 minutes, in one sitting, on the iPad mini. [How to use a checklist](README.md#how-to-use-a-checklist).

## Sitting 1 · Pencil on the iPad mini

Start when `scripts/install.sh` has reported success for the M5 milestone build on the iPad mini, the iPhone and your other Mac. The Mac rows use your other Mac, never the build Mac.

| # | Device | Do | Expect | Result | Notes |
|---|---|---|---|---|---|
| M5.1-01 | iPad mini | Open Knot and touch the Pencil to the capture surface. | An ink segment starts on a blank canvas. The system's handwriting-to-text does not turn the stroke into typed text. | ☐ pass ☐ fail | |
| M5.1-02 | iPad mini | Write "call the vet at noon" and tap Done. | The ink stays as ink in the note. | ☐ pass ☐ fail | |
| M5.1-03 | iPad mini | Search for "vet". | The note from row 02 is found by its handwriting. | ☐ pass ☐ fail | |
| M5.1-04 | iPad mini | Copy that ink segment as text and paste it into a note in Apple Notes. | The pasted text reads "call the vet at noon", or close to it. Write what it says in Notes. | ☐ pass ☐ fail | |
| M5.1-05 | iPad mini | Start a drawing. Touch the canvas once with a finger, and press one key on the keyboard if one is attached. Carry on drawing. | The drawing does not end: one stray touch or key press never ends it. | ☐ pass ☐ fail | |
| M5.1-06 | iPad mini | Keep writing past the bottom of the canvas. | The canvas grows as you write. | ☐ pass ☐ fail | |
| M5.1-07 | iPad mini | Open the note from row 02 and write "and the post office" below the first drawing. Tap Done. | It is a second ink segment in the same note, under the first. | ☐ pass ☐ fail | |

| M5.1-09 | iPad mini | Draw a house with a sun and tap Done. | The stream shows the note as a sketch. No made-up text is recognised from it. | ☐ pass ☐ fail | |
