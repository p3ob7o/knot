# M2 · iPhone voice and text

You can press the Action Button, speak, and find a cleaned, titled note. You can type notes, watch the append window work, search, edit, delete and undo. You can kill the app while recording and lose nothing.

About 60 minutes, in three sittings. [How to use a checklist](README.md#how-to-use-a-checklist). M2 is the keep gate: when this checklist has passed, the M2 milestone build is your only capture tool on the iPhone for seven days.

## Sitting 1 · Triggers and speech

Start when `scripts/install.sh` has reported success for the M2 milestone build on the iPhone. Before the first row:

- Assign Knot to the Action Button, and add Knot's control to the Lock Screen and to Control Center.
- Have the [read-aloud script](G4-read-aloud.md) open on another screen.
- The Mac in row M2.1-10 is the build Mac. On it, run `Fixtures/tools/generate.sh --audio` in the repository first, so that the ten-minute clip exists.
- "Locked" means the iPhone has not unlocked: wake it with the side button while looking away, so Face ID does not unlock it. "Unlocked" means Face ID has unlocked it and the Lock Screen still shows.
