# Named tests. This file lists the tests that the plan and `docs/architecture.md` require by name, each with the package that owns it.
# Lines that start with `#` are comments.
# There is one line for each test, with three fields separated by one tab character:
#   1. the owner, a package ID such as WP-10, or one of its pull requests, such as WP-30 PR 1;
#   2. a slug of lower-case words joined by hyphens, unique in this file, which the test's code carries;
#   3. the test, in one sentence, in the words of the plan or of `docs/architecture.md`.
# A test that the plan gives to more than one package has one line for each of them.
# The lines are ordered by owner.
# The gate fails when a listed test is missing once its package has merged, or, for a test given to a pull request, once that pull request has.
