## Failure rules

- Every build that is not a milestone build uses development identifiers, and that covers agent builds. Only a milestone build opens the default store or the real iCloud container.
- Agents use `knot-dev` and never `knot`, and their threads export `KNOT_AGENT=1`.
- No automated test and no agent opens a hardware microphone on the build Mac.
- From the M4 milestone build on, no milestone build is installed or run on the build Mac.
- A fix built for an earlier milestone is made at that milestone's level. A fix made for M2 during the keep-gate week therefore carries nothing from M3 or M4.
- A fix found during the keep-gate week ships as a new M2 build with a tested migration, because the owner's iPhone notes are real from M2 on.
