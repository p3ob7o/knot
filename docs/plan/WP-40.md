The ruling is the owner's keep-gate ruling. At the keep-gate sitting he rules one of four ways: continue as planned, continue with cuts, revise the spec first, or stop the build. Until that ruling, wave 4 does not start, and that holds back this package. The keep-gate week runs on the M2 milestone build as it is, in the system look and with the structure of the chosen direction. Seven days pass between the M2 checklist and the start of wave 4 work. The orchestrator records the ruling in `docs/decisions/keep-gate.md`.

The handoff comes from the full Claude Design round, which the owner runs at gate G2 after the direction. It is committed to `docs/design/handoff/`. Before WP-40 starts, the orchestrator checks the handoff against the state matrix of docs/design/brief.md §6: every cell is designed or inherits from a named cell, and each capture surface is shown at the largest text size, with Reduce Motion and with the keyboard up. Gaps go back to the designer as a list, not as a second round. The owner reads that gap list at G2. The handoff is accepted when that check has passed.

If the full design round has run by the ruling, the orchestrator lists what the ruling changes in `docs/design/deltas.md` and sends that list to the designer, as it does for a gap.

WP-40a to WP-40d each start after their platform's app package has merged. That package is WP-30 for the iPhone, WP-35 for the iPad, WP-33 for the Mac and WP-32 for the Watch.

A part that the owner cuts is not started. The orchestrator then updates the briefs in `docs/plan/` and the checklists in one PR.

## Failure rules

- Where a mock and a system component differ, the system component wins and the deviation is recorded. Type maps to Dynamic Type text styles, colour to roles and materials to system materials. Controls, complications, widgets and the Live Activity take glyphs, strings and content from the handoff and rendering from the system.
- Where the handoff is silent, the implementer uses the system default and adds a line to `docs/design/deltas.md`, which the owner clears at M6.
- Where the design changes structure, the orchestrator lists each difference in `docs/design/deltas.md` and assigns it. This package's ownership extends to the view models those differences touch.
- If the design handoff arrives late or changes structure, the cost is UI rework. Behaviour lives in view models. Views are thin and restyled in this package.
- A test fails when a cell marked as designed has no named preview. It reads the state matrix from the brief's own table.
- Every UI smoke test runs the system's accessibility audit. Exclusions sit in one file, each with a reason (docs/architecture.md §17). WP-41 makes the audit clean on every designed cell.
- From the M4 milestone build on, no milestone build is installed or run on the build Mac. For a Mac, `scripts/install.sh` writes the build to a folder the owner names, and he opens it there.
