# The steps of the merge gate, scripts/verify.sh --gate (docs/architecture.md §18).
# Lines that start with `#` are comments. Each line has four fields separated by one tab:
#   1. the step, as scripts/verify.sh names it;
#   2. its state: `required` runs in the gate now, `pending` does not run yet;
#   3. what it waits for, or the package that delivered it;
#   4. what it checks.
# The gate reads field 2: a pending step is listed in its output and not run. A pending
# step becomes required when what it waits for has happened; the orchestrator changes the
# line. Which steps a gate takes at all comes from the depth table of §18, applied to the
# diff by scripts/lib/knot_tool.py.
#
# The gate builds with the pinned Xcode only: it refuses KNOT_XCODE when it names another
# Xcode than .xcode-version pins. It refuses --only, --module and --skip. It refuses
# KNOT_LOCAL_CONFIG, which would give its builds settings that no other run has, and it
# fails when a step it should run is skipped.

doctor	required	WP-01	The machine: no cloud-synced folder, the disk floor, the pinned Xcode and XcodeGen, the simulator runtimes, and the on-device models.
plan	required	WP-01	scripts/check-plan.sh.
links	required	WP-01	Every relative link in a Markdown file resolves.
fixtures	required	WP-04	Fixtures/tools/generate.sh --check: the committed fixtures match a fresh run, and the generated audio has its format and length.
format	required	WP-01	swift format lint --strict with .swift-format.
pins	required	WP-01	GRDB's version and revision for SwiftPM and for Xcode, and no other dependency.
team-id	required	the owner's local configuration, on the build Mac since 2026-11-20 (KNOT_TEAM_CONFIG)	The signing team's ID from the owner's local configuration is in no tracked file. At every depth. Without the configuration the step is skipped, and the gate fails on a skipped step.
lint	required	WP-01	No network call, logged text, standard defaults domain, eraseDatabaseOnSchemaChange, unlisted concurrency escape, undeclared required-reason API, test that cancels itself, or file named "… 2"; and the nightly workflow makes the audio before the package tests under Thread Sanitizer.
ownership	required	WP-01	The diff stays inside the paths the package owns, from its brief and scripts/ownership-extra.txt.
core-api	required	WP-01	KnotCore's public API matches the base, except on a contract branch.
named-tests	required	WP-01	Every test in docs/plan/named-tests.txt exists once its package has merged.
package-build	required	WP-01	The package and its tests build, with --explicit-target-dependency-import-check error.
package-test	required	WP-01	The package tests, Swift Testing, on the Mac. A skipped or cancelled test, or a cancelled case, read from the console or from the run's event stream, fails the gate, because the gate requires the models; a stream that is missing or did not end fails the step.
package-test-strict	required	WP-01	The package tests once more with LIBDISPATCH_COOPERATIVE_POOL_STRICT=1, one pool thread for each priority, so that a test whose wait blocks a pool thread hangs here as on the three-core hosted runner; at its limit it names the tests that started and did not end. A skipped or cancelled test fails the gate.
contract-two-targets	required	WP-01	A contract suite in KnotTestSupport runs from two test targets.
self-test	required	WP-01	The scripts' self-test.
apps	required	WP-01	Every app builds: the iOS app with the Watch app and both extensions, and the Mac app with knot-dev.
packaging	required	WP-01	The packaging proofs of docs/plan/WP-01.md, with Release binaries free of KnotFakes.
ios-hosted	required	WP-01	The tests hosted in the iOS app in the iPhone simulator: the contract suites that run only there. At the leaf depth, where the diff reaches KnotAudio, KnotInk or the iOS app.
launch	required	WP-01	The UI tests on the iPhone, iPad and Watch simulators, and the Mac app's window.
mac-ui	required	WP-01 PR 3	Mac UI tests, on the exclusive slot, where the diff reaches the Mac app, KnotUI, scripts/ or .xcode-version.
soak	pending	WP-06	The capture ledger soak, where docs/architecture.md §17 asks for it.
live-smoke	pending	WP-22	One UI smoke test on each platform on .live with a temporary store.
two-process	pending	WP-34	After G1 and SP-3: the sandboxed app and knot-dev share a store, the tool writes and the app shows it.
